# logosdev - Landing Page Personal

Portafolio profesional de **César Rondón Batista**, Software Developer Full-Stack con sede en Bayamo, Cuba.

## 🌟 Descripción

Este proyecto es una landing page personal moderna y responsive que presenta:
- Perfil profesional y experiencia (+10 años)
- Habilidades técnicas (Frontend, Backend, Herramientas)
- Trayectoria profesional
- Proyectos destacados
- Formulario de contacto

## 🚀 Tecnologías Utilizadas

### Frontend
- **HTML5** - Estructura semántica
- **CSS3** - Estilos personalizados
- **Bootstrap 5.3.3** - Framework CSS
- **Alpine.js 3.13.7** - Interactividad ligera
- **Bootstrap Icons** - Iconografía

### Librerías Adicionales
- **PocketBase JS SDK** - Cliente de base de datos
- **Google Fonts** - Tipografía Ubuntu y Ubuntu Mono

## 🎨 Características

- ✅ **Diseño Responsive** - Adaptable a móviles, tablets y desktop
- ✅ **Modo Claro/Oscuro** - Toggle de tema con persistencia en localStorage
- ✅ **Navegación Suave** - Scroll suave entre secciones
- ✅ **Animaciones** - Efectos reveal y count-up
- ✅ **Formulario de Contacto** - Validación y envío
- ✅ **Filtrado de Proyectos** - Por categoría (Web, Mobile, API)
- ✅ **Accesibilidad** - Etiquetas ARIA y navegación por teclado

## 🛠️ Instalación y Uso

1. **Clonar el repositorio**
   ```bash
   git clone <repository-url>
   cd logosdev
   ```

2. **Abrir en el navegador**
   - Simplemente abre `index.html` en tu navegador
   - O usa un servidor local:
     ```bash
     # Con Python
     python -m http.server 8000
     
     # Con Node.js (npx)
     npx serve
     ```

3. **Acceder**
   - Navega a `http://localhost:8000`
